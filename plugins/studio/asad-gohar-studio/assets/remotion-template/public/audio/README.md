# public/audio/

The music for the video goes here, then gets named in `src/audio.config.ts`.

Nothing in this folder is committed (see `.gitignore`) — tracks are licensed to a
person, not to a repository, so they stay local.

## Only use a track you are allowed to use

Free and clearable sources:

- YouTube Audio Library — studio.youtube.com, Audio Library
- Pixabay Music
- Uppbeat (free tier needs the credit line they give you)
- Chosic
- Anything rendered locally, e.g. a MIDI arrangement through FluidSynth

A copyrighted song gets the video muted, pulled, or claimed, and the credit goes
to whoever wrote it. Record the source in `credit` in `src/audio.config.ts` while
you still remember it — reconstructing attribution a month later never works.
